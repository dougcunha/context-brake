## Pending items for HIL 1

- **PI-01 (non-blocking, identifier scheme).** The PRD uses `RF`/`CA` in Portuguese, sanctioned by `AGENTS.md`; prd-02 and prd-03 kept the same scheme. Recommendation: keep.
- **PI-02 (non-blocking, verification reach).** CA-01, CA-09, CA-12, and CA-14 run against a simulated harness; real-model adherence is explicitly not measured (PRD "Verificação por simulação").
- **PI-03 (non-blocking, platform reach).** Prior features were validated on Windows / Node 24 only; the Linux/macOS CI matrix (`prd-02` O-04) has not run and bounds this feature's evidence equally.
- **PI-04 (non-blocking, product tension RF15 vs autonomy).** With the harness's default permission mode (RF15, CA-11), real non-interactive sessions may stall or deny tools that need approval, so unattended completion on real harnesses depends on the user's own allow rules or an explicit opt-in flag. The autonomy objective is measured only on the simulated harness. Recommendation: accept as stated; the TechSpec documents per-harness behavior under defaults.
- **PI-05 (non-blocking, defaults left to TechSpec).** The PRD fixes only the anti-loop default (2). Defaults for session, total and per-session duration, token ceilings, validation timeout, and the exit codes for success, limit, and human-decision stops are left to the TechSpec. Recommendation: TechSpec proposes them for HIL 2.
