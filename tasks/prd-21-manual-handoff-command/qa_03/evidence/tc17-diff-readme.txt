298:- **Manual handoff:** type `/handoff [focus]` to move the work to a new session at any time, in any zone. The command asks the agent to run the `snapshot.command` skill or, without one, to save `.context-brake/handoff.md`, and to end its reply with `[REQUEST_SESSION_RESET]`; the restart then runs as above. The optional focus (500 characters at most) tells the snapshot or the handoff what the next session must do first, and is never written to a log. A typed `/handoff` counts as your prompt, so it resets the loop guard. Without automatic restart it prints how to turn it on; with `CONTEXT_BRAKE_AUTO_RESTART=0`, `DISABLE_AUTO_COMPACT`, or a session that is not interactive it prints the skip notice and does nothing. Typed during a turn, it runs when the turn ends. If the agent does not end its reply with the signal, nothing restarts; type `/handoff` again.
318:Without a snapshot command, automatic restart uses a markdown handoff. From the trigger zone, the action asks the agent to save a handoff to `.context-brake/handoff.md` and end its reply with `[REQUEST_SESSION_RESET]`. An automatic restart needs a handoff written during that turn. The next session start moves it to `.context-brake/handoffs/` (the last 10 are kept) and tells the agent to read it and continue. `init` adds `.context-brake/.gitignore` so handoffs stay out of Git; `remove` keeps them.
